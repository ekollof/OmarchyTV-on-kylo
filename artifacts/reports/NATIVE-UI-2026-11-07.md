# Native OmarchyTV shell — first functional screen — 2026-11-07

Status: offline native UI milestone. No TV, fb1, GPU or takeover operation.
The vendor skin remains the fallback.

## What changed

`mod_ui_omarchy` is no longer a three-rectangle skeleton. It is a native shell
over `ui.engine` with:

- a **Home** grid of four 300x180 tiles: Sources, Apps, Settings, About;
  2D Up/Down/Left/Right focus and a 4 px accent focus frame;
- a **Sources** screen listing TV, BACK AV, HDMI1–3, YPbPr, VGA/PC,
  Wireless Display and AV Share. Select calls `OA_SVC_SOURCE.select_type` with
  the recovered source type (WiDi/AV Share are marked unavailable) and emits
  `OA_TOPIC_ACTION` `OA_ACTION_SOURCE` on success; Exit emits `OA_ACTION_BACK`;
- an **Apps** screen that reads `OA_SVC_LAUNCHER_DB` via `read_parent(0)` and
  lists up to eight application names; it filters deleted/out-of-sync rows and
  de-duplicates names (the earlier `read_all` path showed 54 hidden/duplicate
  rows on the TV; the live list showed 19). Select emits `OA_TOPIC_ACTION`
  `OA_ACTION_SELECT` with the row index and app name; the list reloads when
  `launcher.db` changes or is removed;
- a **Settings** screen showing `m_current_source` and `m_cec_enabled`;
  Select on CEC toggles the setting through `OA_SVC_SETTINGS`;
- an **About** screen identifying the native shell;
- a live `HH:MM` header clock (30 s owner timer), accent rail and footer hints;
- optional EF41 text from `ui.font_index`/`ui.font_pack` (body id 9, title id 2;
  measured heights 24 and 30 px); without the pack the geometry/focus still paints. No vendor skin assets,
  portal, telemetry, advertising or ACR path is used.

The prior 14 px accent rail and tile-0 rectangle are preserved as stable
signatures, so existing recorder assertions remain meaningful. The shell uses
`clear_rgba`, `fill` and `blit` only; it does not take display ownership.

## Key map

```text
19 / 20   Up / Down
21 / 22   Left / Right
53 / 0x8a Select
10 / 48   Exit / back
0xf0      project skin switch (skin diag, unchanged)
```

Home focus indexes 0..3 in row-major order. Exit returns Home from every
sub-screen; Select on Home opens the focused screen. A loaded Lua script may
claim keys the native shell does not handle.

## Action contract

There is no in-process app-launch service; `OA_TOPIC_ACTION` is the seam used
by the vendor apps grid. The native shell emits:

```text
OA_ACTION_SELECT  Apps row index + application_name
OA_ACTION_SOURCE  source type + source label, only after source.select_type == 0
OA_ACTION_BACK    leaving a sub-screen (screen id in index)
```

A future app-manager/IPC action consumer can launch the named application
without the native skin owning process lifecycle. No process is spawned by the
skin itself.

## Limits

- The Apps screen is read-only; selecting an app does not launch it or emit the
  vendor `OA_TOPIC_ACTION` yet.
- The Sources screen's actual VIN switch only succeeds when `source.enable=1`
  and the real platform is running; the UI shows the service result but the
  hardware path is unaccepted.
- The CEC toggle needs the real settings DB; the panel action is untested with a
  live writable database.
- Text uses the TV's EF41 pack; no bundled open font yet.
- The module is included in the full bundle but **not autoloaded**; the vendor
  `ui_vendor` skin remains active by default. Selecting `ui.skin=omarchy` or
  loading/starting `ui_omarchy` is an explicit runtime action.
- No visible scanout, input-device, animation or cold-start acceptance.
