# Owned amplifier I2C transport — 2026-11-04

`common/amp_i2c.c` adds an owned blocking session for the fixed MB230 AD82587
endpoint, bus3/address34. The maintained amp-probe now uses its read-only mode.
The exact new native probe read03..05 successfully on the TV; no register write,
GPIO, MCU, initialization or framebuffer operation was performed.

## Session and error contract

- Open copies the explicit syscall table or selects native ARM32 syscalls,
  opens only /dev/i2c-3 and validates the **opened fd** as char89:3. Checking
  after open avoids the old stat/open identity race. Non-ARM native mode rejects
  ENOTSUP. Native ARM32 i2c_msg/ioctl-list sizes are compile-time checked.
- The session owns its fd. It does not own the amplifier/bus exclusively or
  initialize HAL/PreInit/GPIO/MCU. Callers establish hardware authority and
  serialize calls on a blocking owner; callback code/context remain borrowed
  through close. No input/request buffer can be retained by transfer callbacks.
- Read is limited to registers03..05. Its temporary reply is copied out only
  after exactly two messages complete. Writes require explicit allow_write=1,
  accept registers0..37 and one byte only, then delay10ms after complete success.
  The CLI has no write command and opens with allow_write=0.
- APIs return negative errno. The Init callback adapter converts success to1
  and every failure to0, with the original negative error available separately.
  Passing negative errno directly to Init would falsely signal vendor true.
- Short replies (including0/1) and unexpected positive counts reject EIO.
  **This is stricter than vendor HAL's nonnegative-success test**, and continues
  the original probe's exact-count policy. It is a deliberate error-policy
  deviation, not bug-for-bug failure parity. EINTR is not replayed; an error
  does not promise that a hardware write had no effect or can be rolled back.
- Inherited handles reject ECHILD before I/O. Linux final-close failure still
  consumes the fd and clears/frees the session; never replay that descriptor.
  This is fd release, not physical amp shutdown or the CEC hardware-close rule.
