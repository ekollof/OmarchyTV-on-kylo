# Injected AD82587 Init orchestration — 2026-11-04

`common/amp_init.c` implements the shipped Init control sequence with explicit
caller-owned image/cache state and injected callbacks. It performs no native
I/O by itself. There is no default backend, device acquisition, module hookup,
worker or paired shutdown. All testing was offline; TV access remains forbidden.

The source is the recovered AMP_AD82587_Init@874ef0, Reset@874dac and
Mute@874e50. Their ARM/decompilation is already preserved in AUDIO-AMP-IMAGE,
audio-lifecycle-2026-11-04/amplifier-methods.txt and the earlier
cec-ownership-2026-11-01/amp-board-transport.txt. Fresh local ELF checks verify
Init598 bytes CRC1fba7b2d, Reset162/ef9e3238 and Mute158/0fc39805. Native
comparison uses these complete unmodified bodies; no firmware bytes embedded.

## Preserved control semantics

- Board prelude; first mute getter/direction/Mute(0);5ms; reset getter, optional
  direction/configured level/20ms/inverted level/10ms; second mute getter and
  direction; Reset(1)/10ms/Reset(0), Mute(0)/1000ms; image patch;38 writes.
  First write failure waits10ms, calls Mute(1) and returns0. Success calls the
  subwoofer enable getter (only raw1 enables), enable/init,10ms, Mute(1), return1.
- Second mute getter may return a different record. No prefetched single
  resource snapshot replaces those repeated getter semantics.
- Reset(1) selects configured level_off; Reset(0) uses logical !level_off,
  including noncanonical levels. Mute selects level_on/off. Raw reset-pin
  operations in Init do not update the private reset cache. Reset/Mute helper
  calls update only their byte cache on a nonzero lower level return.
- GPIO/direction errors do not stop native Init. A nonzero GPIO return, even
  negative, is treated as true. The injected callback contract is vendor-style
  boolean; errno-returning native transports require an adapter. Init's1/0 is
  the write-loop result, not GPIO/subwoofer success or audible acceptance.
- The image remains fully patched after write failure. Caller supplies its
  initial/retained image and cache bytes; no guessed baseline is compiled in.
  Invalid arguments return-EINVAL before any callbacks/state change, an explicit
  bounded API policy rather than vendor invalid-object fault parity.

The caller must serialize access and retain state, profile/name, callback code/
context and returned GPIO records until completion. Delays and I/O can block;
run on an owning worker after device authority is established, never the host
loop or quiescence hook. No cancellation or rollback guarantee is added.

## Verification

`tests/amp_init.c` covers the present/absent resource sequence, exact1055/1025ms
delay arguments (no actual wait), write failure at every position, ignored GPIO
failure, cache/image retention, subwoofer exact-one policy and invalid-call
atomicity. Strict host, leak-enabled ASan/UBSan and fresh ARM/qemu pass.

`tests/amp_init_native.h` compares **29,952** complete traces/image/cache/return
cases against the shipped bodies: four reset/mute presence combinations, four
reset levels, four mute level pairs, twelve GPIO failure masks and all38 I2C
failure positions plus complete writes. Failure masks include each individual
level operation, combined Reset/Mute failures and all-level failure. Direction
results alternate0/7; successful level results alternate-1/7; subwoofer raw
values cover0/1/2/ffffffff. The second mute record has a different pin/levels.
All private cache bytes other than the two flags and the image guards stay intact.

Lower GPIO/I2C/delay/subwoofer/board/profile calls are controlled callbacks;
diagnostic logging is excluded from the control trace. Thus this is orchestration
parity, not a GPIO/MCU/I2C backend or hardware effect/timing test. Real Reset/Mute
instructions execute and perform cache writes, rather than being fake no-ops.
