# Diagnostic skin `ui_diag` — 2026-11-05

Reloadable diagnostic skin over `ui.engine`. It probes a representative set of
project services, paints a green/red status table, and lets Up/Down select a
row and Select re-probe. This is a module/service harness, not a vendor screen.

## Behavior

Rows: `ui.engine`, `display`, `settings`, `launcher.db`, `service.list`,
`epg.ingest`, `tuner`, `pvr`, `audio.curve`, `input`, `ui.portal`, `ui.lua`.

- Green = provider present; red = absent. Details show dimensions,
  source/state/count/value where the interface exposes them.
- Up/Down wraps the selected row; Select and Exit/Menu repaint; module-change
  events repaint automatically.
- Optional EF41 text uses `ui.font_index`/`ui.font_pack` (defaults to the
  vendor2 pack) and `ui.diag.font`/`ui.diag.title_font` (7/18). If the pack is
  unavailable the colored rows and selection still render.
- `m_suspend`/`m_resume` unregister/re-register the skin and reload fonts;
  ordinary stop/unload/reload is covered.

The socket test switches `omarchy -> diag -> vendor` on a running host with the
recorder display. The ARM module also builds:

```
build-tv-v3/modules/mod_ui_diag.so
```

## Limits

- Fixed 12-service probe list, not dynamic host enumeration; a loaded module is
  visible only if it publishes one of the probed services.
- The status table is a project harness, not vendor UI/geometry/font parity.
- No hardware, TV, fb1, HAL or cold-start acceptance. Recorder display only.
- Text layout is the existing EF41 line draw, not the vendor text engine.
